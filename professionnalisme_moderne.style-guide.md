# Style Guide — Professionnalisme Moderne

## Overview
A modern flat design approach with clear hierarchy, professional teal tones, and structured information architecture. Designed for a job search platform requiring clarity, accessibility, and trustworthy sophistication.

## Platform
Web

## Mode
Light

## Color Palette

### Primary Color
- **Deep Teal**: `#0B7A75`
- A professional, trustworthy tone that conveys stability and modernity
- Used for: Primary actions, links, key interactive elements

### Background
- **Light Gray Base**: `#F7F8F9`
- Very light gray with barely perceptible cool tint
- Creates a clean, professional foundation without harshness of pure white

### Accent Colors
- **Soft Blue-Gray**: `#5C7B89`
  - Used for: Secondary actions, supportive information
- **Slate**: `#475569`
  - Used for: Tertiary elements, subtle emphasis

### Functional Colors
- **Text Primary**: `#1E293B` (dark slate)
- **Text Secondary**: `#64748B` (medium slate)
- **Success**: `#059669` (emerald green)
- **Warning**: `#D97706` (amber)
- **Error**: `#DC2626` (red)
- **Border**: `#E2E8F0` (light slate)

### Surface Colors
- **Surface Level 1**: `#FFFFFF` (white cards on gray background)
- **Surface Level 2**: `#F1F5F9` (subtle gray for nested sections)
- **Surface Level 3**: `#E2E8F0` (lighter slate for inactive states)

## Typography

### Font Family
- **Primary**: Inter, system-ui, -apple-system, sans-serif
- Clean, modern sans-serif optimized for UI readability

### Font Weights
- **Regular**: 400 (body text)
- **Medium**: 500 (labels, secondary headings)
- **Semibold**: 600 (primary headings, emphasis)
- **Bold**: 700 (hero titles, important CTAs)

### Type Scale
- **Hero/Display**: 48px / 700 weight / -1% letter-spacing
- **H1**: 32px / 600 weight / -0.5% letter-spacing
- **H2**: 24px / 600 weight / normal letter-spacing
- **H3**: 20px / 600 weight / normal letter-spacing
- **H4**: 18px / 500 weight / normal letter-spacing
- **Body Large**: 16px / 400 weight / normal letter-spacing
- **Body**: 14px / 400 weight / normal letter-spacing
- **Body Small**: 12px / 400 weight / normal letter-spacing
- **Label**: 14px / 500 weight / normal letter-spacing

### Line Height
- **Headings**: 1.2
- **Body text**: 1.5
- **Compact text** (labels, buttons): 1.4

## Spacing System
Based on 8px grid for consistent rhythm

- **XS**: 4px
- **SM**: 8px
- **MD**: 16px
- **LG**: 24px
- **XL**: 32px
- **2XL**: 48px
- **3XL**: 64px

## Border Radius
Subtle radius for modern refinement

- **None**: 0px (rare, for specific design intentions)
- **Small**: 4px (buttons, inputs, small cards)
- **Medium**: 8px (cards, containers, modals)
- **Large**: 12px (hero sections, large feature cards)
- **Round**: 9999px (pills, avatars, badges)

## Boundaries & Elevation
Flat design with clear structural hierarchy through surface color differences

### Approach
No shadows, subtle surface color differences with clear contrast for structural boundaries and functional hierarchy

### Surface Differentiation
- **Background → Surface Level 1**: Clear contrast (F7F8F9 → FFFFFF)
- **Surface Level 1 → Surface Level 2**: Subtle contrast (FFFFFF → F1F5F9)
- **Borders**: Used sparingly for input fields and dividers (`#E2E8F0`, 1px)

### Visual Hierarchy
- Clear color contrast defines importance and interaction zones
- Interactive elements use Primary color for prominence
- Hover states: 10% darker shade of base color
- Active states: 15% darker shade of base color
- Disabled states: 40% opacity

## Components Style

### Buttons
- **Primary**: Deep Teal background, white text, 4px radius, medium padding (12px 24px)
- **Secondary**: Soft Blue-Gray background, white text, 4px radius, medium padding
- **Tertiary**: Transparent background, Deep Teal text, 1px border, 4px radius
- **Text Button**: No background, Deep Teal text, no border

### Input Fields
- Background: White
- Border: 1px solid `#E2E8F0`
- Border radius: 4px
- Padding: 10px 12px
- Focus state: Border color changes to Deep Teal, no shadow

### Cards
- Background: White
- Border radius: 8px
- Padding: 24px
- Elevated from background through color contrast (no shadow)

### Navigation
- Background: White
- Border-bottom: 1px solid `#E2E8F0`
- Links: Medium slate text, Deep Teal on hover/active

### Badges & Tags
- Background: Surface Level 2 (`#F1F5F9`)
- Text: Text Secondary (`#64748B`)
- Border radius: 9999px (pill shape)
- Padding: 4px 12px
- Small size: 12px font

### Lists & Tables
- Row separator: 1px solid `#E2E8F0`
- Hover state: Background changes to `#F8FAFC`
- Zebra striping: Not used (flat design preference)

## Design Principles

### Clarity
- Clear visual hierarchy through size and color contrast
- Generous whitespace for breathing room
- Consistent spacing patterns

### Accessibility
- WCAG AA contrast ratios minimum
- Clear focus indicators
- Readable font sizes (minimum 14px for body)

### Efficiency
- Scannable layouts with clear sections
- Visual grouping of related information
- Prominent CTAs for key actions

### Trust & Professionalism
- Consistent color application
- Professional color palette
- Refined details without overdesign

### Modern Web Standards
- Responsive design principles
- Component-based thinking
- Performance-conscious (no heavy shadows or effects)

## Feel
Professional clarity • Organized information architecture • Modern web standards • Trustworthy sophistication
