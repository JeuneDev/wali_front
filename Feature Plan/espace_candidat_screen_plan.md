# Espace Candidat
Fournir au candidat une vue d'ensemble de son activité sur la plateforme et un accès rapide à ses principales fonctionnalités.

Layout Hierarchy:
- Header (Full-width):
  - Navigation principale
- Main Content Area (Centered container):
  - Vue d'ensemble
  - Mes candidatures récentes
  - Actions rapides
  - Recommandations

## Navigation principale
- Logo de la plateforme
- Liens de navigation : Accueil, Rechercher des offres, Mon espace (actif)
- Avatar utilisateur avec menu déroulant : Mon profil, Paramètres, Déconnexion

## En-tête de l'espace candidat
- Message de bienvenue : "Bonjour [Prénom]"
- Statut du profil avec indicateur de complétude : "Votre profil est complet à 85%"
- Lien : "Compléter mon profil"

## Vue d'ensemble - Statistiques
- Cartes de statistiques (sur une ligne) :
  - Nombre de candidatures envoyées
  - Candidatures en cours d'examen
  - Offres sauvegardées
  - Profil consulté par X recruteurs (cette semaine)

## Mes candidatures récentes
- Titre de section : "Mes candidatures récentes"
- Tableau ou liste de candidatures (5-8 candidatures récentes) :
  - Pour chaque candidature :
    - Titre du poste
    - Nom de l'entreprise
    - Date de candidature
    - Statut : Envoyée, Vue, En cours d'examen, Rejetée, Acceptée
    - Lien : "Voir les détails"
- Bouton : "Voir toutes mes candidatures"

## Actions rapides
- Titre de section : "Actions rapides"
- Cartes d'actions cliquables :
  - "Rechercher des offres" avec icône
  - "Modifier mon profil" avec icône
  - "Mes offres sauvegardées" avec icône et compteur

## Recommandations d'offres
- Titre de section : "Offres qui pourraient vous intéresser"
- Message : "Basées sur votre profil et vos recherches"
- Cartes d'offres recommandées (3-4 offres) :
  - Titre du poste
  - Entreprise
  - Localisation
  - Type de contrat
  - Badge "Correspond à votre profil"
  - Bouton : "Voir l'offre"

## Conseils et ressources
- Titre de section : "Conseils pour votre recherche"
- Cartes de conseils ou articles (2-3 items) :
  - Icône illustrative
  - Titre du conseil
  - Courte description
  - Lien : "Lire la suite"
