# Mon Profil
Permettre au candidat de consulter et visualiser son profil professionnel complet.

Layout Hierarchy:
- Header (Full-width):
  - Navigation principale
- Main Content Area (Centered container):
  - En-tête du profil
  - Informations personnelles
  - Formation
  - Expériences professionnelles
  - Compétences

## Navigation principale
- Logo de la plateforme
- Liens de navigation : Accueil, Rechercher des offres, Mon espace
- Avatar utilisateur avec menu déroulant

## En-tête du profil
- Photo de profil ou avatar
- Nom complet du candidat
- Titre professionnel
- Localisation
- Indicateur de complétude du profil avec barre de progression
- Bouton : "Modifier mon profil"

## Informations personnelles
- Titre de section : "Informations personnelles"
- Adresse email
- Numéro de téléphone
- Date de naissance
- Nationalité
- Adresse complète

## Formation
- Titre de section : "Formation"
- Liste des formations (3-5 formations) :
  - Pour chaque formation :
    - Diplôme obtenu
    - Établissement
    - Dates (année de début - année de fin)
    - Spécialisation ou mention

## Expériences professionnelles
- Titre de section : "Expériences professionnelles"
- Liste des expériences (3-6 expériences) :
  - Pour chaque expérience :
    - Poste occupé
    - Nom de l'entreprise
    - Dates (mois/année de début - mois/année de fin ou "Actuellement")
    - Description des responsabilités (2-3 lignes)
    - Localisation

## Compétences
- Titre de section : "Compétences"
- Compétences techniques (badges ou liste) :
  - Liste de compétences techniques avec niveau indicatif
- Compétences comportementales (badges ou liste) :
  - Liste de soft skills

## Préférences de recherche
- Titre de section : "Préférences de recherche"
- Secteurs d'activité recherchés
- Types de contrats souhaités
- Localisations préférées
- Disponibilité

## Documents
- Titre de section : "Documents"
- CV téléchargé avec date et lien de téléchargement
- Autres documents (diplômes, certifications) avec liens
