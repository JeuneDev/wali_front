# Espace Recruteur
Fournir au recruteur une vue d'ensemble de ses offres actives, des candidatures reçues, et un accès rapide aux fonctionnalités de gestion.

Layout Hierarchy:
- Header (Full-width):
  - Navigation principale
- Main Content Area (Centered container):
  - Vue d'ensemble
  - Offres actives
  - Candidatures récentes
  - Actions rapides

## Navigation principale
- Logo de la plateforme
- Liens de navigation : Accueil, Espace recruteur (actif), Rechercher des candidats
- Avatar utilisateur avec menu déroulant : Profil entreprise, Paramètres, Déconnexion

## En-tête de l'espace recruteur
- Message de bienvenue : "Bonjour [Nom recruteur]"
- Nom de l'entreprise
- Bouton principal : "Publier une nouvelle offre"

## Vue d'ensemble - Statistiques
- Cartes de statistiques (sur une ligne) :
  - Nombre d'offres actives
  - Candidatures reçues cette semaine
  - Candidatures en attente d'examen
  - Taux de réponse moyen

## Mes offres actives
- Titre de section : "Mes offres actives"
- Tableau ou liste d'offres (5-8 offres récentes) :
  - Pour chaque offre :
    - Titre du poste
    - Date de publication
    - Nombre de candidatures reçues
    - Statut : Active, Expirée, En attente de validation
    - Actions : Voir les candidatures, Modifier, Clôturer
- Bouton : "Voir toutes mes offres"

## Candidatures récentes
- Titre de section : "Candidatures récentes"
- Liste de candidatures (6-10 candidatures récentes) :
  - Pour chaque candidature :
    - Photo ou avatar du candidat
    - Nom du candidat
    - Titre du poste concerné
    - Date de candidature
    - Résumé de l'expérience (1 ligne)
    - Statut : Nouveau, Vue, Présélectionné, Rejeté
    - Boutons : "Voir le profil", "Marquer comme vu"
- Bouton : "Voir toutes les candidatures"

## Actions rapides
- Titre de section : "Actions rapides"
- Cartes d'actions cliquables :
  - "Publier une offre" avec icône
  - "Rechercher des candidats" avec icône
  - "Gérer mes offres" avec icône
  - "Profil entreprise" avec icône

## Conseils et bonnes pratiques
- Titre de section : "Optimisez vos recrutements"
- Cartes de conseils (2-3 items) :
  - Icône illustrative
  - Titre du conseil
  - Courte description
  - Lien : "En savoir plus"
