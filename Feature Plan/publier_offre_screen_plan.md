# Publier une Offre
Permettre au recruteur de créer et publier une offre d'emploi complète et structurée.

Layout Hierarchy:
- Header (Full-width):
  - Navigation principale
- Main Content Area (Centered container, medium width):
  - Progression du formulaire
  - Formulaire de création d'offre
  - Actions de soumission

## Navigation principale
- Logo de la plateforme
- Fil d'ariane : Accueil > Espace recruteur > Publier une offre
- Liens de navigation : Mon espace
- Avatar utilisateur

## En-tête et progression
- Titre de la page : "Publier une nouvelle offre"
- Indicateur de progression : Étape 1 sur 3
- Sous-titre explicatif : "Remplissez les informations pour créer une offre attractive"

## Informations de base (Étape 1)
- Titre de section : "Informations générales"
- Champ : Titre du poste (obligatoire)
- Sélecteur : Secteur d'activité (obligatoire)
- Sélecteur : Type de contrat (CDI, CDD, Stage, Freelance) (obligatoire)
- Sélecteur : Niveau d'expérience requis (obligatoire)
- Champ : Localisation du poste (obligatoire)
- Champ : Salaire minimum (optionnel)
- Champ : Salaire maximum (optionnel)
- Case à cocher : "Ne pas afficher le salaire publiquement"

## Description du poste (Étape 2)
- Titre de section : "Description du poste"
- Zone de texte enrichi : Description générale du poste
- Message d'aide : "Décrivez les missions principales et le contexte de travail"
- Zone de texte : Responsabilités principales
- Message d'aide : "Listez les principales missions (une par ligne)"
- Zone de texte : Avantages offerts
- Message d'aide : "Décrivez les avantages sociaux, conditions de travail, etc."

## Profil recherché (Étape 3)
- Titre de section : "Profil du candidat idéal"
- Zone de texte : Formations ou diplômes requis
- Zone de texte : Compétences techniques requises
- Message d'aide : "Listez les compétences clés (une par ligne)"
- Zone de texte : Compétences comportementales souhaitées
- Zone de texte : Expériences spécifiques souhaitées
- Champ date : Date de clôture de l'offre (optionnel)

## Informations entreprise
- Titre de section : "Votre entreprise"
- Champ : Nom de l'entreprise (pré-rempli)
- Zone de texte : Présentation de l'entreprise
- Message : "Ces informations proviennent de votre profil entreprise"
- Lien : "Modifier mon profil entreprise"

## Prévisualisation et publication
- Bouton : "Prévisualiser l'offre"
- Message d'information : "Votre offre sera visible immédiatement après publication"
- Bouton principal : "Publier l'offre"
- Bouton secondaire : "Enregistrer en brouillon"
- Bouton tertiaire : "Annuler"

## Barre de navigation du formulaire
- Bouton : "Précédent" (si pas à l'étape 1)
- Bouton : "Suivant" (si pas à la dernière étape)
- Indicateur : Étape actuelle / Total d'étapes
